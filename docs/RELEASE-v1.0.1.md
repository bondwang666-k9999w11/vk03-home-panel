# VK03 Home Panel v1.0.1

控制中心改为文件夹版 EXE，运行库通过同目录 `_internal` 文件夹提供，不再每次启动解压到临时目录，避免本次测试发现的 `ucrtbase.dll` 解压权限错误。

下载 `VK03-v1.0.1-core.zip` 后完整解压到 `C:\VK03`。必须保留 `_internal`，不要只复制 EXE。实际屏幕进程仍需 Python 及 requirements.txt 中的依赖。

从 v1.0.0 更新：退出控制中心并停止面板，备份本机配置，再覆盖程序文件并添加 `_internal`。保留自己的 `vk03_config.json`、`vk03_theme.json`、背景素材、FFmpeg 和已配置的传感器组件；公开包不含这些个人文件。无需重新创建快捷方式，EXE 文件名不变。

独立目录验证：ZIP 解压后的 EXE 窗口与四页预览自检通过，退出码 0；使用此前全新安装依赖的隔离 venv，配置、模拟设备匹配、凭据保存、首次启动和空闲导航共 11 项测试通过。全新系统 USB 驱动安装及实机控制没有在本次验证，托盘未在本次自检中测试。

详细步骤见 [入门教程](QUICKSTART.md) 和 [安装说明](INSTALL.md)。
