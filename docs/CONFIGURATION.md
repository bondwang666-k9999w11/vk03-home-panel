# 本机配置

`C:\VK03\vk03_config.json` 由设备向导创建，包含 HA 地址、当前用户 DPAPI 加密 Token 和设备映射。**加密后的 Token 和设备映射也属于个人数据，不要提交到仓库。**

配置格式示例在 `examples/vk03_config.example.json`，实体都是演示名称，加密 Token 为空。不要把示例文件直接当作有效凭据使用；通过向导填写自己的配置。

`schema_version` 当前为 1，`bindings` 有 10 个固定角色。每项包含 `entity_id` 和 `label`。四个灯位置只接受 `switch`/`light`，空调接受 `climate`，净化器接受 `fan`，环境参数接受 `sensor`。空实体代表未使用。

显示名称最多 24 个字符，卡片自动省略过长内容。映射按角色固定位置展示，暂不提供拖拽排序。设备能力、实际状态和单位来自 HA，不在配置中伪造。

`vk03_theme.json` 保存个人背景路径、字体颜色、帧率、按钮深浅色、透明度等。程序复制导入素材到安装目录，公开包不含素材。

`vk03_pc_sensor.json` 由面板进程每秒发布 PC 监控数据，设置窗口使用同一份数据；过期数据不会显示为当前值。CPU 温度 helper 使用独立的 `vk03_cpu_sensor.json`。

URL 验证拒绝内嵌用户名密码、查询参数和片段。默认 TLS 证书验证保持启用，携带 Token 的 HA 请求不会跟随重定向。HTTP 在局域网中传输未加密，跨网络访问应使用正确配置的 HTTPS。

Windows 用户登录后具有读取本机配置的权限；DPAPI 并不能防止同一用户权限的恶意程序读取其凭据。跨机器迁移时重新输入 Token，不能假设密文可以复用。

已有旧版用户：保留原安装目录的配置和背景备份，换开源版后在向导重新选择实体。旧版只有 HA 地址和 Token，没有通用映射，因此不会自动猜测你的设备；加密 Token 可在原用户上留空复用。
