# 与原厂扩展版 0.3.0 的对比

[返回 Studio 首页](../README.md) · [使用教程](USAGE.md)

## 先说明版本线

这里的 **0.3.0 指之前的“原厂软件扩展版”**，使用原厂 Myth.Cool 界面与核心，再注入我们自己的触摸组件。当前 **Studio 0.2.1 是重新开发的独立软件**，版本号从新的产品线开始计数。

本仓库 `main` 保留的米家 / Home Assistant 面板是另一条线；这次独立版放在 `vk03-studio` 分支，未替换主分支。

对比基线来自之前保存的 0.3.0 发布包及其源文件，不把它误称为本仓库已有的 Git 标签，也不把已有功能全部当成新增功能。

## 变化一览

| 项目 | 原厂扩展版 0.3.0 | Studio 0.2.1 |
| --- | --- | --- |
| 运行方式 | 原厂核心、前端页面加扩展代码 | 独立 Qt 桌面程序、自己的渲染器与 USB/HID 通信 |
| 原厂软件 | 扩展包内运行原厂相关组件 | 不加载 MythCool.exe、原厂 JSC 或 .node；仍使用兼容的系统 USB 驱动 |
| 菜单与编辑流程 | 原厂设备页、Widget 选择和预览编辑 | 屏幕编辑、方案库、设备、设置/关于；组件/图层、画布和属性分区 |
| 布局与尺寸 | 自定义触摸组件以固定初始尺寸接入原厂流程 | 可独立调整位置和宽高、复制、调整图层；撤销/重做、自动保存 |
| 字体外观 | 扩展组件文字样式较固定，原厂资源按原有编辑器配置 | 字体、字号、颜色、显隐、文字/底板/图片透明度 |
| 监控文字 | 沿用原厂传感器和原厂布局体系 | 独立 CPU/GPU 四项组件，可选光晕，一键复用文字样式且不改位置/尺寸/内容 |
| 内存组件 | 沿用原厂提供的监控小组件 | 原文字组件之外新增条形、水球、指针仪表盘；显示实际已用/总内存 |
| 水球 | 没有我们自己的动态水球 | 三层不同速度、方向、透明度的波浪液面，跟随内存占用水位 |
| 音量图标 | 喇叭及静音切换，波纹不按音量分级 | 三档递增波纹；0或静音显示小号X；滑条内部颜色可自定义 |
| 画面亮度 | 没有独立触屏亮度组件 | 10–100%软件调暗组件，也可在设备页设置；不控制物理背光 |
| 快捷方式 | 六个固定槽位 | 可添加多个独立快捷按钮，受方案总组件上限80限制 |
| 图片图标 | 已支持居中裁剪、铺满、透明度 | 保留，并整合在独立属性面板中 |
| 媒体控制 | 已支持歌名、播放/暂停、上下曲 | 保留，改为独立 Windows 系统桥接 |
| 背景 | 通过原厂界面设置图片/GIF/视频 | 自己的背景设置与媒体播放；15/30目标FPS；可保留组件并切换纯背景 |
| 关机/重启 | 点按组件后进入确认界面 | 小屏同一按钮在2.5秒内连续点按两次，第一次显示提示 |
| 方案迁移 | 原厂私有方案与扩展快捷设置分开保存 | 独立方案文件，可导出/导入包含素材的 `.vk03` 包 |
| 安装/卸载 | MSI 与解压包 | 当前提供完整免安装包；附 `uninstall.exe`，按清单删除程序并保留个人数据 |

## 本次开发阶段

### Studio 0.1.0

重新设计独立菜单、编辑工作台、图层与属性面板，接入自己的渲染与直接 USB 出图/触摸；媒体、音量、快捷、监控、背景、方案保存均放入独立程序。

### Studio 0.1.1

增加音量分级波纹、小号静音 X、音量/亮度填充色；修复右侧属性栏在窄窗口中的横向裁切。

### Studio 0.2.0

CPU/GPU 四项可选光晕与同族文字样式复用；新增三款内存组件和保留个人数据的卸载入口。

### Studio 0.2.1

水球改为三层错速波浪，动画使用现有帧刷新，不额外开设备读取线程；0/100%边界显示稳定。沿用卸载程序，同时更新新版文件清单。

## 当前边界与尚未搬入的内容

- 原厂皮肤和私有布局没有一键转换功能；独立版提供三套原创初始布局。
- 原厂扩展版的配置不会自动迁移为 Studio 方案；已有 Studio 方案兼容。
- CPU 温度依赖已有 LHM WMI 服务，NVIDIA GPU 依赖已有 nvidia-smi；AMD / Intel GPU 当前未接入，不能把原厂支持的所有传感器覆盖范围套用到独立版。
- 当前公开包为 Windows x64 ZIP，未提供新的 Studio MSI。
- 画面亮度是软件调暗；15/30 FPS为目标值，实际需结合硬件实测。
- Studio 不含 HA 控制；需要家居控制的用户继续使用本仓库 main 分支。

## 验证说明

模型与素材包、Qt离线渲染/编辑、模拟触摸、波浪动画边界与周期、原生 Windows 只读状态、打包 EXE 启动与视频解码、卸载文件保留机制均做过检查。当前开发设备的用户已反馈实屏通过；这些结果不等于所有主机、驱动和固件都已验证。
