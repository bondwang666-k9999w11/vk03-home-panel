# VK03 Home Panel v1.0.0

首次开源版本：PC 监控与 Home Assistant 家居控制共用 VK03 USB 触摸屏。

- PC 监控默认页：CPU/GPU 温度和占用、内存仪表、时间日期；无描边粗体、轻微同色光晕。
- 图片、GIF、视频背景，目标 5–30 FPS，按钮浅色/深色与透明度、字体颜色设置。
- 触摸进入家居页，首次触摸不控制设备；30 秒没有触摸返回监控，家居首页可立即返回。
- 新设备匹配向导：读取自己的 HA 实体，配置四个灯、空调、净化器及环境传感器；不再带任何作者设备 ID。
- 当前用户 DPAPI 加密凭据、托盘、自启动和 HA 自动重连。

核心 ZIP 不含 Python、USB 驱动、FFmpeg、LibreHardwareMonitor DLL 或 PawnIO 安装程序。使用前按安装/设备匹配教程准备环境，CPU 温度和视频组件按需安装。

通用配置版的向导和控制逻辑通过无硬件测试；不同集成/设备型号需要自行验证能力。硬件基础正式版已实测，GPU 当前仅支持 NVIDIA。单文件 EXE 控制中心仍使用外部 Python 运行屏幕进程。
