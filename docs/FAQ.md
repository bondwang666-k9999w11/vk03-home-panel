# 常见问题

[返回首页](../README.md) · [完整教程](USAGE.md)

## 下载后找不到 EXE

请下载 `VK03Studio-0.2.1-preview-win64.zip`，不要把 Source code 当成程序包。完整解压后运行 VK03Studio.exe。

## 提示缺少文件 / DLL，或只复制 EXE 后无法启动

程序需要同目录的 `_internal`。重新完整解压到新文件夹再试，不要混用不同版本的依赖。查看是否有安全软件提示具体文件被隔离，不要盲目关闭系统保护。

## 找不到设备、接口占用、连接失败

先从托盘退出其他VK03程序与MythTool，再检查USB连接。设备应匹配显示345F:9132、触摸374A:A401。当前只支持已确认的MS912C 360×960组合和原始触摸朝向。

缺少64位libusb0库时，需要先准备与当前系统/设备匹配的驱动。程序不会自动替换驱动，也不要求原厂软件保持运行。不要把32位库当作64位库使用；仍无法连接时附错误提示反馈，不要反复重置全部复合设备接口。

## 关闭窗口后程序还在运行

这是托盘模式。右下角托盘右键Studio图标选择退出。启动新版或卸载旧版前，先退出对应版本。

## CPU温度是“—”

目前读取LibreHardwareMonitor WMI的CPU温度。缺少对应服务、没有CPU温度传感器或无法读取时显示“—”。本版不包含自动CPU驱动安装器。CPU占用与内存不依赖该服务。

## GPU占用或温度是“—”

NVIDIA显卡需要系统已有可用的nvidia-smi。AMD/Intel GPU目前没有接入。没有数据不会显示示例值。

## 媒体按钮没有反应

先确认播放器正在播放，并支持Windows系统媒体会话。部分播放器不提供上下曲能力。编辑器的鼠标点击只负责编辑，真实控制在小屏触摸执行。

## 视频卡顿 / 无法播放

目标帧率不是实际保证值。先尝试15FPS及分辨率更接近960×360的素材，检查磁盘是否繁忙。无法解码时换用常见编码的视频。背景没有配置或素材丢失时请重新选择；程序使用自带Qt媒体模块，不要求另装ffmpeg.exe。

## 纯背景模式后组件不见了

取消预览下方“仅播放背景·保留组件配置”。组件仍保存在方案中。

## 为什么内存总量略小于标称值

显示的是Windows报告的物理内存数据，可能扣除硬件保留等空间。容量以1024进制换算显示为GB，保留一位小数。

## CPU/GPU监控如何统一发光字体

选中其中一项，勾选文字光晕并调整字体/颜色等，点击“样式套用到同类组件”。只同步四项监控的文字样式，不改变位置、尺寸或标题。快捷/电源按钮属于另一组。

## uninstall.exe提示目录不可识别

卸载程序必须和该版本的VK03Studio.exe、studio-package.json及files.sha256.json在同一完整程序目录中。不要单独拷贝卸载EXE到其他文件夹运行。

## 卸载后目录或配置仍在

卸载只按清单删除未修改的程序文件。你新增或修改过的文件，以及用户数据目录中的方案与素材会保留；空的程序目录才会被移除。卸载不会删除其他版本或USB驱动。

## 反馈需要哪些信息

请在Issue标题注明[Studio]，提供Studio版本、Windows版本、设备型号、错误文字/截图和复现步骤。不要上传完整个人配置；日志或截图中先隐藏私人路径、网址参数和密钥。
